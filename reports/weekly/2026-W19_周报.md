## 2. 重点论文逐篇要点

### 2.1 fea_surrogate 方向（High 价值精读）

**[[arxiv_2605.09775v1]] vvBO（Vector-valued Bayesian Optimization, EPFL Colin Jones 组）**：把 BO 的"标量观测"换成"linear measurement operator 在 vector-valued RKHS 上的结构化测量"，给出 sublinear regret 上界（separable kernel 下 Gaussian O((log T)^{d+1}√T)、Matérn O(T^{d(d+1)/(2ν+d(d+1))}·log T·√T)）+ 完整理论 + MPC 真实建筑控制实验。**对 fea_surrogate 方向的直接贡献**：FEA 每次昂贵 call 产出整张应力/温度/位移场，下游多个 KPI 是同场的不同 linear functional——vvBO 让"一次仿真服务多个 KPI"成为有 statistical guarantee 的范式。建议把"surrogate 是否能服务多 KPI"加入 [[ADR-0024]] 评分体系。

**[[arxiv_2605.07738v1]] EquiNO + Q-DEIM（TU Braunschweig，3D 超弹性 RVE）**：本周对我研究主线最直接命中的论文。POD-DeepONet 类减阶 + 周期/平衡 by-construction + Q-DEIM hyper-reduction 让 3D finite-strain hyperelastic RVE 训练**比单次 FE 仿真还快**（233 path 训练时间 ≈ 半次单 path FE 仿真），均质化推理 10³–10⁴× 加速。**直接对应电子封装 underfill 多相结构、生物打印梯度 scaffold 的 RVE surrogate** —— 代码声明会开源，是必复现工作。

**[[arxiv_2605.09016v1]] CATO（Cambridge DAMTP + Tsinghua YMSC + Yale FDS）**：**学习连续 chart Φ_chart 把物理坐标映射到 [-1,1]²，再做 charted axial attention**，6 个 PDE benchmark + 15 baseline 上 27% 平均误差降幅，参数 -82%；PCA 分析显示学到的 chart 有效维数 1.126——即"内在 1D 流形"。Plasticity / Elasticity 这两个 FEA benchmark 上明显胜过 Transolver/SAOT。是当下最值得追代码的 PDE operator 工作之一。

**[[arxiv_2605.09096v1]] SpectraNet（New Orleans + NRL）**：U-Net 谱混合 + **Residual-Target Spectral Block (f = id + Δ_θ)** + Semigroup-Consistency Loss，Theorem 1 把 AR rollout 误差从 O(L^T·ε₀) 砍成 O(T·δ)。NS ν=1e-5 上 6/6 benchmark 中 5 胜，CPU 174ms 推理 vs Transformer 10.3s（60× 加速）。**对工程瞬态 FEM surrogate（散热、振动）极有部署价值**，代码已开源在 GitHub。Residual-target 应作为我未来 AR surrogate 默认设计模式。

**[[arxiv_2605.07828v2]] NSPOD（Synopsys + Brown / Karniadakis）**：DeepONet 训完→生成多个扰动解→POD 提取 prolongation P→构造 MG-like 预条件子 M⁻¹=P(PᵀKP)⁻¹Pᵀ。"加速既有 FEM solver"而非替代——Synopsys 商业级 EDA 视角，对电子封装 FEM 加速极有工业价值。AMG 之上还能显著提升 Krylov 迭代次数。

**[[arxiv_2605.09523v2]] HS-FNO（Georgia Tech）**：处理 non-Markovian 时间维度的"提升状态到 history space + shift-append 精确传输+ FNO 预测新切片"。AR rollout 误差 0.094 vs H2H 0.185（仅用 1/28 参数）。对粘弹性、塑性 hardening 等 history-dependent 本构的 FEM surrogate 有方法学迁移空间。代码已开源。

**[[arxiv_2605.07060v2]] functional-prior B-PINN（JAMSTEC + Kyoto + RIKEN）**：FPI-BPINN 把 GP functional prior 通过 MMD 学进 NN weight prior；fParVI-PINN 直接在函数空间做 SVGD。RFF 是 represent GP 的关键。Darcy / 地震走时反演验证。**对电子封装"材料参数贝叶斯反演"是 ready-to-use 工具栈**。

**[[arxiv_2605.12544v1]] DCP-INN（电子科技大 + 绵阳中心医院）**：双网络（菱形 N_main + 宽深 N_corr）+ Taylor 邻域损失，Vessel 4 高曲率上把误差从 41.49% 降到 12.87%。**最值得记住的对照**：单网络 PINN 加 Taylor 损失反而恶化到 41.49%——说明"算法层补丁"在复杂几何上必败，必须从架构 inductive bias 入手。这是本周最 dramatic 的 ablation 信号。

**[[arxiv_2605.08672v1]] B-PINN 理论（UMN, ICML 2026）**：在 spike-and-slab + 无界幅值先验下证明 B-PINN 后验在 PINN-loss 范数上 near-minimax 速率 n^{-(β-2)/(d+2(β-2))}(log n)^{1/2}，rate-adaptive。配合下界 Theorem 3.5 是完备的统计基础。

**[[arxiv_2605.09362v1]] FrameTwin（CUHK + Manchester）**：曲线锚定高斯 + 神经变形场，从 8 张稀疏视图构建线框 3D 打印数字孪生。生物打印的 in-situ 监控可直接套用（需先解决透明水凝胶成像问题）。

### 2.2 fea_surrogate 方向（Medium 但有 takeaway 的工作）

**[[arxiv_2605.08408v1]] AdamFLIP（Purdue + MIT + Harvard Na Li）**：把 PINN 训练改成 equality-constrained 优化，用 control theory 的 feedback linearization 设计 Lagrange multiplier 更新，约束违反量收敛到稳定线性。NS 上 L2 降 >2/3。**作为 PINN 默认 trainer 候选**。

**[[arxiv_2605.11001v1]] FVM-PINN（Penn State, Xiaofeng Liu）**：核心发现是 physics-only loss landscape 上的 trivial zero-momentum minimum 仅比真解大 7×（极易陷入）；加入稀疏数据后 separation 扩到 310×。**"physics-only 失败需 data guidance"是普适教训**，应作为 PINN 设计 anti-pattern 加入评分体系。

**[[arxiv_2605.06203v1]] ACT block（Cambridge DAMTP + HIT Shenzhen + HK PolyU）**：层内 plug-and-play 的 adaptive coordinate transform；揭示 "intermediate tracker / final regularity modulator" 自动 role decoupling 现象。与 CATO 是"global chart vs distributed local transform"对照。

**[[arxiv_2605.07279v1]] PFNet（Shanghai U. + CAS 力学所）**：phase-field 演化 surrogate，**Shannon entropy 作为 trajectory-adaptive disorder 指标 + κ FiLM 注入**。score-based diffusion 与相场动力学的数学等价（drift = score of Boltzmann）是优雅 motivation。

**[[arxiv_2605.06011v1]] DCT-based de-homogenization for TPMS（Osaka U.）**：本应高于 Medium——实验数据极端 dramatic（提出方法 +54.2% 刚度 vs PM 方法 -77.3%，同一 homogenization 优化结果差 131 个百分点）。**"de-homogenization 决定整个设计 pipeline 成败"** 是核心 takeaway。

**[[arxiv_2605.03548v2]] PerFlow**：1-step rectified flow + constraint-preserving projection 做 PDE 重建 + UQ，比 guided diffusion 快 320×。

**[[arxiv_2605.03710v1]] Joint VI for posterior-predictive**：在 FEM 固体力学例子上验证，amortized VI 直接给联合分布，省去两阶段近似。是本周 UQ 工具箱的实用补充。

**其他值得点名的方法学论文**：[[arxiv_2605.02597v1]] Isotropic FNO（旋转对称性，3D 参数 -96×）、[[arxiv_2605.08170v1]] FNO Sobolev approximation bound（H¹ loss 训练 FNO 是简单改进）、[[arxiv_2605.02871v1]] multi-fidelity surrogate 综述。

## 3. 跨论文趋势与共同主题

### 3.1 **"结构性归纳偏置 > 损失函数补丁"** 是本周最强的设计哲学共识
- DCP-INN：单网络 + Taylor 损失补丁失败 → 双网络架构成功（41.49% → 12.87%）
- CATO：fixed Cartesian + 强 attention 失败 → 学习 chart + axial attention 成功（3.7× 误差降）
- ACT block：fixed Eulerian 失败 → 逐层 adaptive coordinate transform 成功
- SpectraNet：direct prediction L^T blow-up → residual-target id+Δ 线性漂移
- HS-FNO：current-state Markovian 假设失败 → history-space 状态化 + shift-append
- EquiNO：soft penalty BC/equilibrium 失败 → reduced basis 硬约束化

**统一信号**：当 baseline 在复杂场景下系统性失败时，**第一选择应是改架构 / 改归纳偏置，而不是加 loss 项 / 调权重**。这一原则应加入 [[ADR-0024]] surrogate scoring 评分体系作为核心维度。

### 3.2 **Bayesian UQ 工具箱在本周完成补全**
- **理论**：[[arxiv_2605.08672v1]] B-PINN 后验集中速率
- **工程实现**：[[arxiv_2605.07060v2]] functional-prior B-PINN（MMD + RFF + GP prior + pSGLD+R）
- **多尺度 SDE**：[[arxiv_2605.09718v1]] normalizing flow VI
- **联合后验-预测**：[[arxiv_2605.03710v1]] amortized VI（FEM 案例）
- **快速 1-step**：[[arxiv_2605.03548v2]] PerFlow（rectified flow + projection）
- **共形 + NF**：[[arxiv_2605.08561v1]] CONTRA、[[arxiv_2605.03233v1]] 条件 conformal
- **PFN 体系**：[[arxiv_2605.06413v1]] decoupled PFN epistemic-aleatoric

这构成完整光谱：从理论保证（B-PINN 集中），到 prior 设计（functional），到 propagation（NF VI），到联合分布（amortized），到 1-step（rectified），到 calibration（conformal）。**未来工程 UQ 工作可分层引用这套组合**。

### 3.3 **几何复杂度处理**形成一个独立研究 thread
- CATO：global chart
- ACT block：层内 distributed transform
- FVM-PINN：unstructured mesh + Roe solver
- NURBS-PINN（[[doi_10.1016_j.jcp.2026.114980]]）：IGA 几何参数化
- NSPOD：Synopsys 商业 CAD 几何
- de-homogenization for TPMS（[[arxiv_2605.06011v1]]）：DCT-based wavenumber alignment

**统一观察**：fixed Cartesian + FNO spectral truncation 在 κ（boundary complexity）增加时系统性失败。处理几何复杂度有三大策略：(1) 显式学坐标变换 (CATO/ACT)，(2) 用本身 geometry-aware 的离散化 (FVM/IGA)，(3) 用 attention 做 data-dependent kernel (Transformer 类)。本周 evidence 显示 (1) + (3) 的组合是 Pareto 最优。

### 3.4 **AR rollout 稳定性**成为 PDE surrogate 第二大共性问题
- SpectraNet：residual-target → 线性漂移
- HS-FNO：history transport exact
- PerFlow：constraint-preserving projection
- ZNO：稳定有理滤波（z 域内 by construction）
- 多个工作都引用 Lippe et al. 2023 PDE-Refiner 作 baseline

这是本周第二大集中点，反映领域已从"single-step accuracy"转向"long-horizon stability"。

### 3.5 **FEM-NN hybrid（不替换、加速）作为商业可接受路径**
- [[arxiv_2605.07828v2]] NSPOD：NN-augmented Krylov preconditioner，作者 Synopsys + Karniadakis
- [[arxiv_2605.07738v1]] EquiNO：硬约束 reduced basis + Q-DEIM，不是 PINN 替代
- [[doi_10.1016_j.cpc.2026.110206]] constrained-weight PINN

**工业偏好"NN 作为加速器 / surrogate / preconditioner"而非"NN 替换 FEM solver"**，因为前者保留可解释性 + safety。这是 [[ADR-0024]] 评分体系应反映的维度。

## 5. 对评分体系的反馈（汇总）

3. **"无实验"声明可靠性**：[[arxiv_2605.08672v1]] B-PINN 理论标"无实验"准确；[[arxiv_2605.09718v1]] normalizing flow 标"无实验"是错的（有 tagged particle 实验）。

- "作者 affiliation 是否正规学术 / 工业机构"（provenance 降分项）

### 5.3 流程建议
