## 二、重点论文（按"对 user 实际影响"排序，非按 scorer priority）

### Top-2（W21+W20 整个 pilot 中对 user 最直接相关）★★★

1. **NEST: Neural-Schwarz Tiling**（arxiv:2605.12343v1，Imperial+AI4I）—
   **Geometry-Universal PDE solving + 实例化在 nonlinear neo-Hookean solids**
   （= 生物力学本构！）。3×3×3 voxel patches 学局部 + 经典 Schwarz 算法层全局
   assembly。**直接对接 user 患者特异 FEA 的核心痛点**——训一次 local solver，
   所有患者复用。本周该框架是对 user 工作潜在影响最大的论文。
   **scorer priority=High 正确，但应被 user 单独标记为 W20 头号跟进**。

2. **Real-time hip biomechanics PINN via smart garments**
   （doi:10.64898/2026.05.06.26352104，Griffith PRECISE）— hip 关节角度/力矩/
   接触力实时估计 from IMU+EMG，**直接对接 hip_implant 术后康复 + fea_surrogate
   方法学**。RMSE：角度 <6°、力矩 0.12-0.30 N·m/kg、接触力 6-16%。临床可部署
   的 PINN。**当前 priority=Medium 偏低**——routing 漏判 hip_implant，scorer
   未识别"临床部署级 + 多方向交叉"。详见 §五·5.1。

### High Tier — 神经算子方法学密集创新（本周最强 cluster）

3. **MNO: Martingale Neural Operator**（arxiv:2605.15806v1，UW）— Doob-Meyer 分解
   作为 architectural prior，FNO 双头给 conditional mean + low-rank covariance。
   Wasserstein 距离降 **120×**，~3× 快于 conditional diffusion。**算子学习 + UQ
   的最优雅方案**，单次 forward 给 closed-form mean+variance。
4. **SON: Stochastic Operator Network**（arxiv:2605.17107v1，FSU+ORNL）— DeepONet
   + Stochastic NN + Hamiltonian-SMP 训练。与 MNO 是本周**"算子学习 + UQ"双标杆**，
   两条独立路线同周提出，说明这是真正热点。
5. **MMGUNet: Mask-Morph Graph U-Net**（arxiv:2605.15231v1，Imperial+TUM+NVIDIA）—
   碰撞分析 surrogate，但**"大几何变化 + 跨组件迁移"完全是患者特异 FEA 的方法
   同构**。Barycentric coarse graph morphing + node masking pretraining。
6. **AOT-POT: Adaptive Operator Transformation**（arxiv:2605.15793v1）—
   **PDE foundation model 路线的关键扩展**：解决多 PDE 预训练的算子结构异构性
   （Sinkhorn 投影统一），12 benchmark 平均误差降 40.9%，OOD 89%。
7. **GRAFT-ATHENA**（arxiv:2605.11117v1，Brown，**Karniadakis 组**）—
   self-improving agentic 框架自主发现新数值方法（含**指数收敛 spectral PINN**）。
   验证案例含 shear-thinning 血液流变学（与生物流体相关）。Karniadakis 是 PINN
   原创团队，工作很少不重要。
8. **Compositional Neural Operators**（arxiv:2605.11691v1）— 预训练基础算子模块
   + aggregator 学习非线性交互，与 Therm-FM/AOT-POT 同 "PDE foundation"路线。
9. **IGANets**（doi:10.1007/s00366-026-02312-6）— Isogeometric Analysis + PINN，
   CAD 直接用作 FE 模型（与 NEST 形成对照——voxel vs spline 两条路线）。
10. **Per-Loss Adapters for PINN Gradient Conflict**（arxiv:2605.10136v1）— 低秩
    适配器为每个 loss 创建独立参数子空间，60+ PDE 配置验证。

### High Tier — am_biomedical 方向直接命中

11. **TPMS LPBF Fatigue Multi-scale**（doi:10.1016/j.ijfatigue.2026.109749）—
    IJ Fatigue 上 LPBF TPMS 结构疲劳裂纹扩展多尺度建模，**对 user 髋柄认证有
    直接借鉴**。
12. **SLM Gyroid AlSi10Mg FE**（doi:10.1007/s40964-026-01715-7）— "complex FE
    methods" 评估 gyroid 力学，含**预测方程给任意体积分数**，可直接平移到
    Ti6Al4V 髋柄段。

### 单一 hip_implant 直接命中（重要但 priority 偏低）

13. **Acoustic THA 术中评估**（doi:10.1088/2057-1976/ae6dc9）— 118 例手术的
    cementless 股骨柄初始稳定性声学评估，0.834 准确率，分层验证不同骨质量与
    假体设计。**Medium 偏低，应 High**。详见 §五·5.1。

### Medium 复核要点

- **NiTi LPBF 超弹性**（doi:10.3390/ma19102092）— **10 循环后 9.93% 可恢复
  应变**——本周对 W21 NiTi 综述的具体实验补充。
- **多孔钽 LPBF 55% 孔隙率最优**（doi:10.1111/os.70328）— Orthopaedic Surgery
  期刊，与 W21 多孔钛综述呼应。
- **FDM-钛多孔支架**（doi:10.3390/met16050518）— 弹性模量 1.2-1.6 GPa **完美
  匹配松质骨**——应力屏蔽痛点的关键工艺方向。
- **Collagen 3D 打印纤维**（doi:10.1088/1758-5090/ae6371）— 0.64 GPa 抗拉强度
  + 8.9 GPa 模量**超过天然肌腱**。

## 五、对评分系统 / harness 的反馈

### 5.1 ★ scorer priority 偏低的两类系统性观察（升级为假设）

**两个连续两周的信号**：

a) **临床部署级 + 直接命中 user 方向的论文 priority 偏低**：
   - W20 hip 生物力学 PINN（10.64898/...）—— Medium，应 High
   - W20 acoustic THA 评估（10.1088/2057-1976/ae6dc9）—— Medium，应 High
   - W20 NiTi LPBF 超弹性（10.3390/ma19102092）—— Medium，应 High
   - W20 多孔钽 55% 孔隙率（10.1111/os.70328）—— Medium，应 High
   - W21 LPBF 疲劳 ML（10.1007/s43939-026-00696-2）—— Medium，应 High
   - W21 dental microrough 表面 + push-out 能量 2.5×（10.1016/j.dental.2026.03.145）
     —— Medium，应 High

b) **综述类 priority 偏低**（W21 已观察，本周未新增综述样本）：
   - W21 多孔钛表面综述 + NiTi-X LPBF 综述都被判 Medium。

**假设池**（暂不改 scorer，4 周累计后再决定）：

> 假设 H1：scorer 对"临床外科应用 + 具体临床指标（push-out / 接触力 / BIC /
> 准确率%）"的论文系统性低估，因为它没有方法学新颖度信号。
> 假设 H2：scorer 对主题与 user 核心方向重合度 ≥80% 的综述系统性低估。

记入 backlog，**W22/W23/W24 三周累计 ≥10 篇这类样本后再决定**。

### 5.2 ★ Cross-source dedup gap — 急需 ADR-0026 草案

W20 出现 **4 组**跨源重复（同一论文以 arxiv + OpenAlex 两个 identity_key 出现）：
1. Curriculum-PINN Spatial Correlation
2. Elicitation-Augmented BO
3. Per-Loss Adapters PINN
4. Online Sharp-Calibrated BO

加 W21 的 2 组 figshare 版本重复 = **两周累计 6 组重复**，约 7% 的精读循环
时间被浪费。

**根因**：OpenAlex fetcher 没把 OpenAlex 条目里的 `ids.openalex_works["arxiv_id"]`
或 abstract 中的 arxiv 引用解析出来填到 `arxiv_id` 字段。下次 fetch 同源条目
（即 arxiv 直接 fetch）时被认为是不同 paper。

**建议**：升级为 **ADR-0026 草案**（"OpenAlex 条目的 arxiv_id 回补"）—
fetcher 层从 OpenAlex 响应解析 arxiv_id 并写入。比 ADR-0025（figshare/Zenodo
namespace 规范化）紧迫性更高，因为发生率明显更高。

### 5.3 ★ Harness gate 调优（W20 实战修正）

W20 处理 GRAFT-ATHENA（238KB 真正文）时，**新装的 sanity check 误判为
landing page**——bullet ratio 17.1% 超过 0.15 阈值。**已调整阈值到 0.25**，
通过验证：
- 9 篇 W21 read 全部仍 pass（最高 5.8%）
- 4 篇已知 landing page 全部仍 fail（最低 20.7%，markers 检查同时拦下）
- GRAFT-ATHENA 现在 pass ✓

新阈值在 (bullet < 0.25 AND markers >= 5) 双重保护下稳健。

### 5.4 摘要质量分布观察

W20 64 篇 LLM 摘要质量分布大致：
- **质量优**（数据具体 + 技术名词完整）：约 25 条（含 NEST/MNO/SON/IKNO/MMGUNet/
  NiTi 数据/多孔钽数据/Collagen 强度等）。
- **质量中**：约 30 条。
- **质量偏弱**：约 9 条（含 jmapro LPBF meltpool、本周个别 surrogate 描述）。

整体比 W21 略好——可能因 W20 论文中 arxiv preprint 占比高，原文摘要本身写
得更具体。

### 5.5 PDF 获取失败模式分类（W20 数据）

`not_article_like_or_landing_page`: ~10 篇（新 gate 主要拦下出版商导航页）
`no_open_access_link`: ~12 篇（Elsevier / Wiley / Sage / Emerald / Springer 期刊）
`HTTP 403`: ~3 篇（MDPI 反爬）
`download_error`: ~2 篇（PDF 损坏 / 重定向死循环）
`extract_failed_or_scanned`: ~1 篇（部分扫描 PDF）

**Failure modes 不在 user 控制内**，但 acquisition rate 61% 是 pilot 健康水平。
