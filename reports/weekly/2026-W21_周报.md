## 二、重点论文逐篇要点

### High 优先级（4 篇）

1. **Therm-FM（arxiv:2605.22663v1，精读）**——本周最有方法学价值的一篇。
   USTC + Sheffield 合作。识别 3D-IC 热传导与扩散类 PDE 在算子层级的结构等价，
   把通用 PDE foundation model（Poseidon/DPOT）通过 SwinV2-based neural operator
   + thermal-equivalent EMT 均质化 + 两阶段多保真训练，迁移到芯片热场预测。
   核心结果：HotSpot 基准 Mean error 降低 4.4×–6.9×，工业 IND-32C 上 **10.62×**；
   <20% 训练数据即超 SOTA SAU-FNO；跨芯片适配仅需 10–30 目标样本；多保真训练
   减少 **74.7% 高保真数据生成成本**。**该论文虽应用域是芯片，但范式（foundation
   model + 多保真 + 跨设计迁移）可直接平移到 fea_surrogate 的患者特异 FEA 代理
   建模——这是本周最高优先级跟进方向**。

2. **Geometry-aware energy-based PINN（doi:10.1016/j.compstruc.2026.108285，复核）**
   ——CMA 论文，能量基 PINN + 几何参数化，符合 fea_surrogate 核心方向；摘要偏弱
   未具体说明几何编码方式。值得机构权限取 PDF 后看。

3. **Bioprinting β-CVAE（doi:10.6084/m9.figshare.32345264 与 .v1，两条复核）**
   ——figshare DOI 404 双条目（首次确认 figshare 版本化 DOI 的 dedup gap）。
   β-CVAE + CNN-BO 闭环优化打印形态，ai_bioprinting 核心。值得追原始期刊版本。

### Medium 优先级精读（5 篇核心）

4. **IKNO（arxiv:2605.22182v1，精读）**——NTU + A*STAR 工作。Infinite-order kernel
   neural operator 通过 closed-form 有限近似（resolvent 形式 + Kronecker
   eigendecomposition）把 kernel propagation 推到无穷阶。预处理成本 O(N^3d) →
   O(d·N^3)。在 15 个 benchmark 上多数 SOTA。其中 **Elasticity benchmark（含中心孔
   的不规则网格应力问题）与 user fea_surrogate 直接对接**。建议记入"非规则
   网格 + 大点云"架构候选清单。

5. **LABO（arxiv:2605.22054v1，ICML 2026，精读）**——SJTU + 上海 AI Lab。
   LLM-Accelerated BO：基于 Kennedy–O'Hagan 双保真 GP，把 LLM 当 LLM-fidelity
   信号源，discrepancy-dominance gating（τ=0.75 最佳）决定何时触发真实实验。
   理论 regret bound + 化学/材料 benchmark 验证。**KOH 多保真框架可直接套用到
   "粗 FEA 网格 + 细 FEA"**，无需 LLM 也成立。

6. **LGBO（arxiv:2605.17976v1，ICLR 2026，精读）**——同 Lab 出品，LLM-Guided BO
   通过 region-lifted preference 把 LLM 偏好嵌入到 surrogate mean shift，
   全程参与而非仅初始化。**最强实证：Fe-Cr 电池电解质湿实验 6 次迭代达最佳值
   90%，标准 BO 需 10+ 次**。是本周湿实验证据最有力的工作。

7. **Training-free LLM-AL（doi:10.1038/s41524-026-02136-4，npj CompMat，精读）**
   ——Toronto + Cohere + Vector Institute。无 surrogate 训练，LLM 直接做 AL
   选择器，4 个材料数据集上**实验数减少 > 70%**。与 LABO、LGBO 共同构成
   "LLM-augmented BO/AL 范式三件套"。

8. **NiTi-X LPBF 综述（doi:10.1080/17452759.2026.2666725，精读）**——Twente +
   RMIT + CNR Lecco 合作。系统梳理 NiTi-Hf/Cu/Nb/Fe 三元合金 LPBF 工艺。
   **重要医学线索**：NiTi-Nb 兼具超弹性 + 生物兼容性（Nb 生物可利用性），
   理论上比 Ti6Al4V 更可能缓解髋柄应力屏蔽——值得 am_biomedical / hip_implant
   方向重点跟进。

### 其他精读（4 篇方法学）

- **Neural Compiler（arxiv:2605.22498v1）**：Scheme 表达式 → 可微 PyTorch Module
  的硬约束 hybrid SciML 框架。对生物力学**逆问题与参数识别**有价值，对全场
  代理建模主线价值有限。
- **(ε,δ)-optimal BO stopping（arxiv:2605.22561v1）**：GP-UCB 紧 instantaneous
  regret bound + 停止准则，配套 FEA-in-loop 工程优化使用。
- **PACE-FNO（arxiv:2605.18606v1）**：物理对称性对齐的 FNO，OOD 误差降低 12×。
  仅周期域，对非规则网格未验证。
- **LPBF 疲劳 ML（doi:10.1007/s43939-026-00696-2）**：基于摘要复核——LPBF
  FCC/BCC/HCP 跨晶系疲劳 ANN 预测，R²=0.932，**对 user 髋柄疲劳认证瓶颈
  有直接借鉴**。建议机构权限取 PDF。

### 复核简述（18 篇要点）

- **am_biomedical / hip_implant 友邻**：多孔钛表面综述（cis）、TPMS IWP/Primitive
  设计（IMechE）、骨肿瘤 SLA 支架（figshare 双版本）、Mg-NO 颅骨支架（BMC）、
  Haversian-gyroid 仿生支架（W20 起，未处理）——共同支撑"多孔/梯度结构 + 表面
  功能化 + 时空控释"是 am_biomedical 当前研究热点。
- **fea_surrogate 方法学增强类**：CMA-PINN 诊断（NTK/CKA 分析 PDE 公式优化
  行为）、NPINN+（非局部 BC 波方程）、GMM 课程 PINN、自适应 Kriging 疲劳可靠性
  ——单篇方法 incremental，集合起来支撑 fea_surrogate 工程实践的工具箱。
- **应用域边缘命中**：SSPC PINN（航空电子）、SiP 跨尺度 CNN 代理（半导体封装）、
  Agentic AI 地热油藏——见下方"评分系统反馈"。
- **生物打印 ai_bioprinting**：心脏 iPSC 嵌入打印、光基 3D bioprinting 综述
  ——偏离 user 主线，作为方向背景了解。

## 三、跨论文趋势 / 共同主题

### 趋势 1：LLM + BO/AL 的 SciML 集成范式正在成熟（本周三篇）

LABO（ICML）、LGBO（ICLR）、LLM-AL（npj CompMat）三篇同周出现，覆盖三种范式：
- **保真融合**（LABO）：LLM 当低保真信号源，理论 regret bound。
- **训练自由**（LLM-AL）：完全弃用 surrogate，LLM 直接选实验。
- **偏好引导**（LGBO）：LLM 偏好嵌入 mean shift，全程参与，有湿实验。

三篇集中出现 + 顶会接收 + 湿实验落地（LGBO 6 vs 10+ 迭代），**说明
"LLM-augmented optimization for scientific discovery" 已经从概念证明阶段进入
有理论 + 有实证 + 多范式并存的成熟期**。对 ai_bioprinting 方向（生物墨水配方
优化场景与化学优化高度同构）有直接借鉴价值；对 fea_surrogate 方向需考虑
"LLM 不懂 CAD 几何"的迁移瓶颈。

### 趋势 2：神经算子方法学密集创新（本周 4 篇）

IKNO（无穷阶 kernel）、PACE-FNO（对称性对齐）、Therm-FM（foundation model
适配）、Neural Compiler（hybrid 硬约束）——4 篇从 4 个角度推进神经算子能力边界。
**关键观察**：与 user 直接对接的 Elasticity 类 benchmark 出现在 IKNO 论文中
（中心孔不规则网格），且 PDE foundation model 跨问题迁移开始有可复现案例。
这是 fea_surrogate 方向"下一阶段实战架构"的清晰候选集。

### 趋势 3：am_biomedical 多孔/梯度结构持续热点

本周 jmbbm 径向梯度 SS 晶格（W23 future）、IMechE TPMS IWP/Primitive 梯度、
figshare 骨肿瘤 SLA 复合支架、Mg-NO 颅骨支架等共同确认"功能梯度多孔结构 +
多功能（抗菌 / 药物释放 / 骨整合）"是 am_biomedical 方向的核心趋势。
**对 hip_implant 直接相关**——髋柄骨整合段的梯度孔隙率设计正是同类工作。

### 趋势 4：综述类论文集中（本周 3 篇）

NiTi-X LPBF 综述（精读）、多孔钛表面综述（复核）、光基生物打印综述（复核）。
NiTi 综述对 user 方向最对口（含 NiTi-Nb 生物兼容性线索）；多孔钛综述是直接的
hip_implant 方向背景文献。**建议加入文献库**。

## 五、对评分系统 / harness 的反馈

### 5.1 fea_surrogate routing-noise 诊断（user 关切的核心议题）

**结论**：fea_surrogate 噪声**确实存在但不严重**，27 篇中**约 3–4 篇属于
"应用域偏远 + 方法学新意低"的真噪声**：
- doi:10.1016/j.icheatmasstransfer.2026.111588（SSPC 航空电子 PINN）— 真噪声
- doi:10.1108/ssmt-03-2026-0017（SiP 半导体封装 CNN 代理）— 边缘（方法可借鉴）
- doi:10.2118/232332-ms（地热油藏 surrogate）— 真噪声
- doi:10.1038/s41598-026-50374-9（NPINN+ 波方程非局部 BC）— 边缘长尾

**反例**：Therm-FM 虽然也是"电子"（3D-IC 热）应用，但**因方法学创新极强
（PDE foundation model）被正确判为 High，且实际价值很大**——证明 routing 不应
按"应用域"一刀切，而应按"方法学创新度 × 与 user 方向迁移路径明确度"二维判定。

**建议 scorer prompt 改进**（拟入下版 scorer_v4.txt）：

> 对"PINN / neural operator / surrogate model"主题的论文，若主要应用域为电子
> 封装 / 半导体 / 航空电子 / 能源油气，则按方法学新颖度二分：(a) 方法学有
> foundation model / 大规模迁移 / 新颖架构 → 保留原优先级；(b) 仅是熟悉技术
> 在新应用上的组合 → 降级到 Low。

### 5.2 figshare 版本化 DOI 的 dedup gap（**重要 backlog**）

本周确认两组 figshare concept+version 重复条目：
- `10.6084/m9.figshare.32345264` + `.v1`（bioprinting β-CVAE）
- `10.6084/m9.figshare.32319710` + `.v1`（骨肿瘤 SLA 支架）

**建议升级为 ADR**：fetcher 层对 `10.6084/m9.figshare.*` 和 `10.5281/zenodo.*`
DOI 做规范化——剥去 `.vN` 后缀作为 identity_key 主键，原 DOI 保留为副字段。
**不违反 CLAUDE.md "DOI-only strict dedup, no fuzzy dedup"** ——版本化 DOI 在
DataCite 规范上明确指向同一研究，是规范化而非模糊匹配。

### 5.4 harness 工具层 bug 与改进点

1. **`download_and_extract` 的 200B 阈值过低**（review_harness.py:176）——
   Wiley / Nature / BMC 等出版商的着陆页（4–10KB 全是站内导航）会触发假阳性
   pdf_found。建议阈值上调到 5KB **且**增加"内容性"启发式（如 abstract /
   methods / references 等关键词出现频次）。
2. **pdfplumber fallback 未安装**（已警告一次）——pyproject 应把 pdfplumber 也
   加入 review extras。
3. **`safe_id` 把 OpenAlex fallback URL 转 `https___openalex.org_W...`**——
   文件名不雅观。本周 27 篇中 1 条命中（GMM 课程 PINN）。如未来 OpenAlex
   fallback 增多，可考虑只取 `openalex_W...` 部分。
4. **next 排序已优化为 date-primary newest-first**（pilot 期间发现旧 sort
   是 priority-primary，与 weekly-report 节奏冲突）——已在 harness 中修复。
5. **discover 时间窗 REVIEW_SINCE 已加**——pilot 期间发现旧版会把 11K 历史回填
   全塞进 state，已限制为 6 周窗口。

### 5.5 摘要质量观察

本周 27 条 LLM 摘要中：
- **质量优**（数据具体 + 技术名词完整）：约 12 条（含 IMechE TPMS、Therm-FM 配套、
  dental microrough、Usman Ali LPBF 疲劳等）。
- **质量中等**：约 12 条。
- **质量偏弱**（动机/结果泛化、缺关键技术名词）：约 3 条
  （compstruc geometry-aware PINN、SSPC PINN、bioactmat Mg 支架等）。

**主要弱项**：综述类摘要过抽象（"下一代生物墨水"等无技术含量）；偏理论方法
论文摘要缺关键超参/数据量。建议下版 scorer prompt：对方法部分必须复述具体
技术名词（PINN / CNN / 能量泛函 / SwinV2 等），不可用通用词替代。
