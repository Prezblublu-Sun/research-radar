# Beyond Prediction: Interval Neural Networks for Uncertainty-Aware System Identification

- **id**: `arxiv:2605.11460v1` · 方向 fea_surrogate · 优先级 Medium · **read**（摘要）
- **来源**: arXiv 2605.11460, 2026-05-12（**W20**）

## 核心思路

**Interval Neural Network**：用区间算术传播 NN 不确定性，做 system identification
（系统辨识）。提供级联训练 + 联合训练两种策略。

## 与 user 关联

- 方法学：另一条 UQ 路径（与本周 SON / MNO 的高斯/martingale 不同）。
- 系统辨识 vs 全场 surrogate 是不同问题——user 主线是后者。
- 区间算术在保守不确定性场景有优势（最坏情况界）。
