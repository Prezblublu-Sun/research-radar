Active Learning with Multifidelity Modeling for Efficient Rare Event Simulation

结果· 相比蒙特卡洛等方法，大幅减少高保真模型调用次数且估计准确

English summary & terms
Motivation· To efficiently estimate rare event probabilities while minimizing the number of expensive high-fidelity simulations.
Method· Proposes an active learning multifidelity framework that adaptively decides when to call the high-fidelity model by fusing low-fidelity predictions with a correction term.
Result· The framework accurately estimates failure probabilities with only a small fraction of high-fidelity calls compared to Monte Carlo or variance reduction methods.
Validation· Validated on academic case studies and two finite element models: Navier-Stokes/Stokes and transversely isotropic material models.
