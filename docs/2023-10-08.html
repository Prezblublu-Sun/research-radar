A Corrected Expected Improvement Acquisition Function Under Noisy Observations

Medium FEA & Surrogate Modelling arxiv Transferable Save for project numerical_benchmark UQ
Han Zhou, Xingchen Ma, Matthew B Blaschko arXiv preprint 2023-10-08 link
相关性: 该论文提出的改进期望提升采集函数可提升贝叶斯优化在噪声环境下的性能，可迁移至基于代理模型的植入物优化问题。
边界: No FEA validation, no implant mechanics, no biomedical context.
动机· 噪声环境下经典期望提升方法忽视最优解不确定性，需修正。
方法· 利用高斯过程协方差信息修正期望提升的闭式表达式。
结果· 在异方差噪声下达到亚线性累积遗憾界，优于标准EI。
验证· 在基准函数和神经网络压缩参数搜索上验证。
英文摘要与术语
Motivation· The classic expected improvement acquisition function neglects the uncertainty in the incumbent solution under noisy observations, necessitating a correction.
Method· A corrected expected improvement is proposed by incorporating the covariance information from the Gaussian process model into the closed-form expression.
Result· The method achieves a sublinear cumulative regret bound under heteroscedastic noise and outperforms standard EI on benchmark functions and neural network compression tasks.
Validation· Validation is performed on synthetic benchmark functions and a practical neural network model compression parameter search.

Validation· Supported by theoretical bounds and numerical experiments on parametric PDE problems.
