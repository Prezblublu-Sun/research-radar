相关性: 该论文直接针对水凝胶扩散-变形耦合问题的降阶建模，其POD方法可迁移至植入物生物力学中的代理模型构建，且包含参数识别和不确定性传播，与用户研究方向高度相关。
边界: This paper does not apply the surrogate model to implant or biomechanics design, nor does it handle multi-objective constraints.
动机· 解决水凝胶扩散-变形耦合问题的高计算成本，实现快速参数识别和不确定性传播。

结果· 降阶模型在基准问题和同轴打印案例中表现良好，有效加速了参数识别和不确定性分析。

英文摘要与术语
Motivation· To reduce the computational cost of simulating coupled diffusion-deformation in hydrogels, enabling efficient parameter identification and uncertainty propagation.
Method· Proper orthogonal decomposition (POD) is applied to construct a reduced-order model from the monolithic finite element full-order model, which is then embedded in an optimization loop for parameter identification.
Result· The POD-based reduced-order model accurately reproduces the full-order solution for benchmark and coaxial printing cases, significantly accelerating parameter identification and uncertainty quantification.
Validation· Validation is performed using a benchmark hydrogel swelling problem and a coaxial printing simulation case, comparing reduced-order model predictions with full-order finite element results.
