相关性: 该论文专注于类增量学习，与有限元代理建模、不确定性量化或生物力学设计无关。
边界: This paper addresses class-incremental learning in machine learning and does not involve surrogate modeling, finite element analysis, constraint handling, uncertainty quantification, or any application to implant or biomechanics design.
动机· 解决类增量学习中遗忘和分数不平衡问题
方法· 通过测量模型在冻结随机网络输出上的预测误差来计算类别分数

验证· 在多个标准基准数据集上的分类准确率
英文摘要与术语
Motivation· To address catastrophic forgetting and score imbalance in class-incremental learning without storing exemplars.
Method· Proposes Prediction Error-based Classification (PEC), which uses the prediction error of a model trained on frozen random network outputs as a class score, approximating Gaussian Process posterior variance.
Result· PEC outperforms rehearsal-free methods on all benchmarks and surpasses rehearsal-based methods with moderate buffer sizes on most benchmarks.
Validation· Empirical evaluation on standard continual learning benchmarks including CIFAR-100, ImageNet, and others.
