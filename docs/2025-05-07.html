SetONet: A Set-Based Operator Network for Solving PDEs with Variable-Input Sampling

High FEA & Surrogate Modelling arxiv Transferable Save for project numerical_benchmark
Stepan Tretiakov, Xingjian Li, Krishna Kumar arXiv preprint 2025-05-07 link
相关性: 该论文提出的SetONet方法解决了变输入采样问题，可迁移至生物力学代理模型中的不规则网格或缺失数据场景。
边界: The paper does not apply the method to biomedical or implant mechanics problems, nor does it include uncertainty quantification or constraint handling.
动机· 现有神经算子要求固定有序采样点，限制实际应用。
方法· 提出SetONet，将输入视为无序集合，用置换不变聚合编码。
结果· 在变布局和传感器缺失下误差低于DeepONet基线。
验证· 在四个经典算例和四个点云问题上验证。
英文摘要与术语
Motivation· Existing neural operator surrogates require fixed ordered sensor layouts, limiting applicability to problems with variable sampling or missing data.
Method· SetONet recasts operator input as an unordered set of coordinate-value observations and uses permutation-invariant aggregation within a branch-trunk architecture.
Result· SetONet-Key achieves lower error than DeepONet on fixed-sensor benchmarks and remains robust under variable layouts and sensor drop-off.
Validation· Validated on four classical operator benchmarks and four point-cloud problems including heat conduction, advection-diffusion, and optimal transport.
