Gaussian Process Regression constrained by Boundary Value Problems

High FEA & Surrogate Modelling arxiv Direct Read now numerical_benchmark
Mamikon Gulian, Ari Frankel, Laura Swiler arXiv preprint 2020-12-22 link
相关性: 该论文直接针对边界值问题约束的高斯过程回归，可显著提高有限元替代模型的采样效率和精度，并自然处理约束条件。
边界: This paper does not include uncertainty quantification for predictions, nor does it demonstrate transferability to implant or biomechanics design problems.
动机· 提高边界值问题求解的准确性和稳定性，减少对大量观测数据的依赖。
方法· 结合协同克里金法和边界值问题特征函数的谱展开核，构建约束高斯过程回归框架。
结果· 相比无边界约束的物理信息高斯过程回归，该方法在解推断上更准确、更稳定。
验证· 通过数值基准问题验证，比较了有无边界约束的回归性能。
英文摘要与术语
Motivation· To improve the accuracy and stability of solving boundary value problems with scattered observations of the source term, while reducing reliance on dense data.
Method· A Gaussian process regression framework constrained by boundary value problems is developed, combining co-kriging with spectral expansion kernels in eigenfunctions of the boundary value problem.
Result· The proposed method yields more accurate and stable solution inference compared to physics-informed Gaussian process regression without boundary condition constraints.
Validation· Validation is performed on numerical benchmark problems, comparing the performance with and without boundary constraints.
