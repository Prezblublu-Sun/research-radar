边界: This paper does not address uncertainty quantification, constraint handling, or multi-objective optimization; it focuses on point prediction of strain fields using linear regression.

Validation· Validation was performed by comparing surrogate predictions to finite element results using linear regression and error distribution metrics across multiple activities.
