Scalable Bayesian Low-Rank Adaptation of Large Language Models via Stochastic Variational Subspace Inference

Colin Samplawski, Adam D. Cobb, Manoj Acharya, Ramneet Kaur, Susmit Jha arXiv preprint 2025-06-26 link
相关性: 本文关注大语言模型的不确定性量化，与有限元代理建模及生物力学设计完全无关。
边界: This paper does not address FEA surrogate modeling, simulation efficiency, constraint handling, or biomechanical implant design; it focuses on Bayesian inference for large language models.
动机· 大语言模型幻觉和校准差，需要不确定性量化。
方法· 通过随机变分子空间推理在低秩子空间进行贝叶斯推断。
结果· 仅需少量参数即可达到竞争性能，并扩展到最大贝叶斯模型。
验证· 在标准LLM基准上评估困惑度和校准误差。
English summary & terms
Motivation· Large language models suffer from hallucination and poor calibration, motivating the need for uncertainty quantification.
Method· Stochastic variational subspace inference is performed on an r-dimensional subspace using LoRA parameters as projection matrices for Bayesian inference.
Result· The approach achieves competitive performance with state-of-the-art methods using only ~1000 additional parameters and scales to the largest Bayesian LLM to date.
Validation· Evaluation is conducted on standard LLM benchmarks using perplexity and calibration error metrics.
