Mengxia Dai, Wenqian Luo, Tianyang Li arXiv preprint 2025-04-06 link
相关性: 该论文关注医学图像分割中的假发现率控制，与FEA代理模型或植入物设计无直接关联。
边界: This paper does not address FEA surrogate modeling, expensive simulation sampling, constraint handling, uncertainty quantification for biomechanics, or implant design optimization.
动机· 医学分割模型置信度校准不足，高风险场景易误诊。
方法· 基于共形预测构建风险感知动态阈值机制，校准损失函数控制FDR。
结果· 在测试集上严格界定了FDR指标，兼容主流分割模型。

Method· A conformal prediction-based quality control framework with a calibration-aware loss function dynamically adjusts segmentation thresholds to bound the false discovery rate below a user-defined risk level.
Result· The proposed method rigorously controls the expected FDR on test data while remaining compatible with standard segmentation architectures.
Validation· Empirical validation on PASCAL VOC format datasets demonstrates effective FDR control without architectural modifications.
