Error analysis for POD Approximations of infinite horizon problems via the Dynamic Programming approach

Alessandro Alla, Maurizio Falcone, Stefan Volkwein arXiv preprint 2015-11-01 link
相关性: 该方法利用POD降阶模型求解高维最优控制问题，其误差分析和采样策略可迁移至生物力学中FEA替代建模以提高采样效率。
边界: This paper does not address FEA surrogate modeling for implant or biomechanical design; it focuses on optimal control and HJB equations without any biomedical context or constraint handling.
动机· 高维非线性最优控制问题计算成本高，HJB方程存在维数灾难。
方法· 利用POD降阶模型逼近动力学系统，推导先验误差界并提出自适应采样策略。
结果· 数值实验验证了误差界和采样策略的有效性，降低了求解复杂度。
验证· 通过数值算例对比降阶模型与全阶模型的精度。
English summary & terms
Motivation· Solving high-dimensional optimal control problems with dynamic programming is computationally prohibitive due to the curse of dimensionality in the Hamilton-Jacobi-Bellman equation.
Method· A reduced-order model is constructed using proper orthogonal decomposition (POD) for the dynamical system, and an a-priori error analysis guides a new sampling strategy for the POD basis.
Result· Numerical experiments demonstrate that the proposed error bounds and sampling method yield accurate approximations while significantly reducing computational cost.
Validation· The approach is validated on benchmark optimal control problems by comparing the POD-ROM solution to the full-order solution.
