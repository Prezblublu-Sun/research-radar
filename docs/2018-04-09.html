Motivation· To alleviate data sparsity in recommender systems by combining active learning with cross-domain collaborative filtering.
Method· A multi-domain active learning framework that queries ratings based on item and user criteria to improve system performance.
Result· The proposed approach outperforms baselines on multiple recommendation tasks across three datasets.
Validation· Evaluated on Movielens, Netflix, and Book-Crossing datasets using standard recommendation metrics.
