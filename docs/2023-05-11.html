Deep Finite Volume Method for Partial Differential Equations

Medium FEA & Surrogate Modelling arxiv Transferable Save for project numerical_benchmark
Jianhuan Cen, Qingsong Zou arXiv preprint 2023-05-11 link
相关性: 提出一种基于有限体积的深度学习PDE求解方法，可替代PINN用于生物力学仿真，但未涉及植入物设计优化。
边界: No biomechanics application, no implant design, no FEA surrogate for design optimization.
动机· 现有深度学习方法求解PDE计算成本高，对非光滑解精度差。
方法· 基于有限体积法的弱形式损失函数，将高阶导数转化为一阶导数。
结果· 在保持或提升精度的同时大幅降低计算成本，非光滑解误差降低两个数量级。
验证· 数值基准测试，与PINN、DRM、WAN等方法对比。
英文摘要与术语
Motivation· Existing deep learning PDE solvers suffer from high computational cost and poor accuracy for nonsmooth solutions.
Method· A deep learning framework using a finite volume-based loss function derived from local conservation laws, transforming high-order derivatives to first-order via automatic differentiation.
Result· Achieves equal or superior accuracy while drastically reducing computational cost, with relative errors up to two orders lower for nonsmooth solutions.
Validation· Numerical benchmarks compared against PINN, Deep Ritz Method, and Weak Adversarial Networks.
