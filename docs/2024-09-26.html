Motivation· Monitoring elusive rhinos is challenging, so the authors propose mapping communal defecation sites (middens) to infer spatial behavior for anti-poaching efforts.
Method· They build classifiers using multimodal remote sensing imagery (thermal, RGB, LiDAR) and design an active learning system, MultimodAL, with ranking to handle extreme class imbalance.
Result· Active learning achieves competitive performance with 94% fewer labels than passive learning, and midden maps reveal clustering patterns that can guide ranger patrols.
Validation· Validation is performed on a real-world dataset of South African rhino habitats, comparing active and passive learning performance.
