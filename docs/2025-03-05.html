Method· A model-free, tuning-parameter-free conformal prediction framework is applied to regression problems in insurance.
Result· The method provides valid predictions with guaranteed coverage probability, demonstrated on simulated and real insurance data, meeting Solvency II requirements.
Validation· Validation is performed using both simulated datasets and real insurance claim data.
