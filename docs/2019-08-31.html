边界: This paper does not evaluate stress shielding or stiffness matching for biomedical implants, nor does it include fatigue testing or osseointegration assessment.
动机· 研究具有径向梯度孔隙率的钛合金多孔晶格的可制造性和压缩性能。

Result· Gradient structures enhanced plateau stress, with the I2Y series showing an 185% increase; stress-strain response depended on both porosity and cell geometry.
Validation· Validation included dimensional accuracy via micro-CT, surface morphology via SEM, and mechanical properties via universal testing machine.
