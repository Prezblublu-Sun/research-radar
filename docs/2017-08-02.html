ELFI: Engine for Likelihood-Free Inference

Medium FEA & Surrogate Modelling arxiv Transferable Save for project numerical_benchmark UQ
Jarno Lintusaari, Henri Vuollekoski, Antti Kangasrääsiö, Kusti Skytén, Marko Järvenpää et al. arXiv preprint 2017-08-02 link
相关性: 该论文的BOLFI方法通过代理模型加速似然推断，可迁移用于生物力学FEA采样效率问题。
边界: This paper does not specifically address FEA, implant design, constraints handling, or biomechanics; it is a general-purpose LFI software library.
动机· 提供灵活的似然自由推断框架以加速基于仿真的推断。
方法· 开发Python库ELFI，用图结构组织推断组件，集成BOLFI代理模型加速。
结果· ELFI支持多核与集群并行，BOLFI可加速推断数个数量级。
验证· 通过标准基准案例验证软件功能与加速效果。
英文摘要与术语
Motivation· To provide a flexible and extensible software framework for likelihood-free inference that can accelerate simulation-based parameter estimation.
Method· ELFI implements a graph-based composition of LFI components and uses Bayesian Optimization for Likelihood-Free Inference (BOLFI) with surrogate modeling to reduce the number of simulator calls.
Result· The BOLFI method within ELFI achieves several orders of magnitude speedup in inference, and the library supports parallel execution and modular extension.
Validation· Validation is performed through numerical benchmarks and example applications typical for LFI, demonstrating correctness and computational gains.
